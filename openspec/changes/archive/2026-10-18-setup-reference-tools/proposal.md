# Proposal: setup-reference-tools

**Owner:** reference-analyst · **Reviewers:** qa-engineer
**Requirements:** SEC-01, SEC-02, PRC-09 · **Decisions:** D-013 · **VISION:** references; plan "Token and context strategy"

## Why
Phase 1 reads the pilot's clips through contact sheets, never single frames, to save tokens (PRC-09). The tools that make them must write only into the ignored `reference/_frames/`, and must never carry a reference file name into anything.

## What Changes
- `tools/reference/extract_frames.py`: extracts stills from one clip in `reference/` at a given rate and time window, named by the clip's **letter**, into `reference/_frames/<letter>/`, with an index of timestamps.
- `tools/reference/contact_sheet.py`: tiles 12–24 extracted stills into one labelled sheet image in `reference/_frames/<letter>/sheets/`.
- pytest tests on a synthetic clip generated by ffmpeg in a temporary folder.

## Capabilities
### New Capabilities
- `reference-frames`: extracting stills and contact sheets from the pilot's clips, OPSEC-safe.

### Modified Capabilities
- none

## Non-goals
- No analysis of real footage in this change (that is phase 1).
- No attitude tracking or wind statistics (the Godot tools stay in the old repo).

## Impact
New `tools/reference/`. Uses ffmpeg (9.0.2) and Pillow (12.3.0), both measured on the dev machine.
