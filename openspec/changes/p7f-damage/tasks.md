# Tasks: p7f-damage

Complex tier (D-033). Branch `unity/physics/p7f-damage` off `unity/main` once `p6-flight-core` 1.6b and `p6-world-query-gallery` (`MapWorld`, the range's strikes) are on `unity/main`. 1.1a and 1.1b run in parallel (disjoint files), each on its sub-branch `unity/physics/p7f-damage--<task>` merged into the change branch; the physics tasks after them run one at a time, since each moves `Propulsion` or `ContactModel` and re-records the goldens it moves; 1.4 waits for `p7a-ground` 1.15 (the seam) and may run after 1.6 if 7a is later; 1.9 runs once 1.8 has landed `DamageReport`.

Every physics task re-records the goldens it moves and audits them against its parent with the new mechanism off, replays a recorded flight bit for bit, and runs `dotnet test tools/simtests`, `dotnet run -c Release --project tools/flightbench -- --golden`, `--contacts`, `--damage` (from 1.3) and `python tools/hygiene/precommit.py --tree HEAD`. A task that touches `assets-src/` also runs `python -m pytest tools` and `python tools/assets/fetch.py --verify`. Unity's EditMode (Mono) goldens are owed when the GPU is free and are run in 1.8.
