# Tasks: p7a-ground

Complex tier (D-033). Branch `unity/physics/p7a-ground` off `unity/main` once `p6-world-query-gallery` (the map world, its queries and budgets) and `p6-flight-core` 1.6b (the range's contacts, the skid's same-face rule, the seam rule) have landed there. Three lanes run in parallel within the cap of four (D-036), each task on its own sub-branch `unity/<prefix>/p7a-ground--<task>` merged into the change branch:
- **World** (world-builder): 1.2 → 1.3 → 1.4; 1.9 after the asset lane's records.
- **Assets** (asset-artist): 1.5 → 1.6 (one generator); 1.7, 1.8 and 1.8b in any order.
- **Physics** (physics-engineer): 1.1 first (it runs at once); 1.10 after 1.1; then 1.11–1.16 as their inputs land, one at a time (each re-records the range goldens); 1.17 and 1.18 after them; 1.19 last.

Every physics task re-records the goldens it moves and audits them against its parent with the new mechanism off, replays a recorded flight bit for bit, and runs `dotnet test tools/simtests`, `dotnet run -c Release --project tools/flightbench -- --golden`, `--contacts` and `python tools/hygiene/precommit.py --tree HEAD`. Every world task runs `dotnet run -c Release --project tools/worldbench -- --golden` in Debug and Release. Every asset task runs `pwsh tools/build_asset.ps1 <ID>` twice (the second leaves `git status` clean), `python -m pytest tools` and looks at its review sheet.
