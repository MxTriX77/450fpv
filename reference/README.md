# reference/ (local only)

Put your real flight footage and photos here, for example `reference/terrain/`.
Git ignores everything in this folder except this README, so none of it is ever committed or pushed.

**Why:** raw combat footage can give away positions through terrain, landmarks, OSD coordinates, timestamps and file metadata.
The team studies it on this machine only. The repo gets only derived material: written observations, colour palettes, and stills you have cleared yourself. That material goes in `docs/reference-notes/`.
