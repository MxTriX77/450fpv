## Things that bite (all in `docs/environment.md` too)
- **Unity Hub must be running** for any batchmode run (MSIX licence sandbox); a dead run leaves `unity/Temp/UnityLockfile`.
- **`git lfs checkout` in every new worktree** before Blender or Unity work; otherwise pointer files import nothing and the capture still exits 0 (task 1.4 makes it fail loudly).
- **`Unity.exe` needs `| Out-Host`** in PowerShell.
- **Agent worktrees:** the harness creates `.claude/worktrees/agent-<id>`; after a handoff run `git worktree unlock`, `git worktree remove --force`, `git worktree prune`, `rm -rf` the folder, delete the `worktree-agent-<id>` branch, then push the role branch. Parallel tasks of one change use `--<task>` sub-branches; merging them conflicts only on `tasks.md` ticks (take both).
- **Model:** while the session model is Fable, briefs about trenches, craters, wrecks or damage get flagged; spawn those agents with `model: "opus"` (memory note).
- **Scratchpad:** agents leave crops from the letters there; clear it after image-heavy tasks (`reference/` content may live only under `reference/`).
- **The hooks are live** on the main checkout (`core.hooksPath .githooks`): they refuse clip names, dates in notes, coordinates, long subjects, bodies. A date in an object sheet is a finding; attribute it to a decision instead.
