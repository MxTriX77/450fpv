## 3. Decisions and rulings this session
- **D-037** (above). The parity criterion for vegetation LODs is now **"No LOD switch pops"**: at each switch the incoming LOD against the outgoing one, at 50 m the shown LOD against LOD0, within 6 % luminance and 15 % coverage, day and overcast, each value the mean over 64 sub-pixel offsets with its standard error under 1 %. LOD0 is not a reference past its own switch (its sub-pixel leaves drop out of the raster).
- The review stage lifts an asset only by `max(0, -min.y)` (L01 task 1.6).
- Physics material rows are per touching part (`p1-materials-per-part`).

## 4. How this session ran (additions to the 2026-10-18 handover's §6)
- When the previous session's agents are still alive, ask the pilot, then message that session to stand down and forward its agents' handoffs; pick up from their commits.
- Every merge commit made by the orchestrator passes `-c user.name=Orchestrator -c user.email=orchestrator@450fpv.local`.
- Long spec edits on a lane branch: a Python script in the scratchpad, run against a scratchpad worktree; check the commit's exit code before removing the worktree (a refused commit plus `worktree remove --force` loses the edit).
- A sub-branch (e.g. `--impostor2`, `--farcards`, a `unity/techart/...` measure) lands on the change branch by fast-forward when it was cut from the tip, else by a merge commit with the Orchestrator identity; tasks.md conflicts resolve by keeping each side's tick.
- The machine runs four agents' Blender and Unity builds at once: a V01 build-and-measure cycle takes 15–25 minutes under that load.
