# Roadmap

Milestones follow CLAUDE.md §5.

| # | Milestone | Exit criteria | Status |
|---|---|---|---|
| M0 | Scaffold | Repo, team, OpenSpec and workflow in place | in progress |
| M1 | Map feedback rounds | User has reviewed representative terrain patches, key objects and textures, and the map format is agreed | not started |
| M2 | World build (noclip) | Full map explorable with mouse + WASD (Shift for fast); user gives final map feedback | not started |
| M3 | First MVP | Main menu (Train / Calibrate / Exit), RadioMaster TX12 calibration, flyable drone with physics logging | not started |
| M4+ | MVP iterations → release | User flight feedback loop | not started |

Before M1: the user drops flight footage into `reference/terrain/`.
